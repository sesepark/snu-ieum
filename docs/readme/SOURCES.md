정장과 패턴은 공식 공개 PNG의 비례·색상을 유지하여 배치했다. 패턴은 원본 전체를 사용하고 자르거나 모티브를 재구성하지 않았다. 교직원 전용 고해상도 다운로드는 사용하지 않았다. 학생 제작 주체를 표시하며 공식 운영 서비스로 표현하지 않는다.

화면은 2026-10-31의 실제 웹 및 390×844 모바일 브라우저 검사에서 기록했다. 64초 영상은 표지 4초, 실제 조작 화면 54초(0.5초 간격), 체험 링크 6초로 구성했다. 개인 연락처가 없는 기관 이용절차 페이지를 원문 예시로 사용한다.
