# 카탈로그 데이터

개발 웹/API의 기본 데이터는 `college-draft.json`이다. 12개 학과의 교수 후보 323명·연구실 70곳, 공용 장비 후보 209개·공간 20곳, 출처 있는 관계 65개, 학과별 논문 근거 12건을 포함한다. 추가 교수 283명은 공식 교수검색의 이름·소속·직위만 있는 후보로 분야·홈페이지·주소·현직 교차 대조가 필요하다. **사람 승인 전 검수 초안**이며 공개 배포 데이터가 아니다. 건축학과 교수의 분야 대표성과 지도 연구실은 추가 확인이 필요하고, 확인되지 않은 관계는 만들지 않았다.

개별 사실과 선정 이유, Raw/Staging 반입 기록은 [drafts/README.md](drafts/README.md)에 있다. Node.js 24에서 다음 명령으로 같은 초안을 재생성한다. 동일 ID의 내용이 다르면 중단하며 승인 배치를 합성하지 않는다.

```sh
node --import tsx data/compile-draft.ts
```

운영 데이터는 사람 승인 후 worker로 내보낸 `public-snapshot.json`을 `IEUM_SNAPSHOT_PATH`로 지정한다. 운영 API는 PostgreSQL 승인 배치가 필수이고, Pages 출시 게이트는 현재 prototype을 거부한다.

## 고정 테스트 표본

`prototype.json`은 2026-10-26 공식 공대 학과 목록과 컴퓨터공학부 교수·연구실 상세 페이지에서 직접 확인한 표본이다. 개인 연락처와 원문 전체는 저장하지 않았다. 이름·소속·연구실 관계·연구 분야의 허용 메타데이터만 수록했다. 출처 URL과 확인일은 파일에 포함한다.

알고리즘·생물정보·인지 분야에서 서로 다른 연구실을 골랐다. 전수/대표성 검증이나 사람의 공개 승인에 해당하지 않는다. 모든 자원은 verificationRequired이며 manifest는 prototype이다. 장비·공간·다른 학과·논문 근거 수량은 아직 미달이다.

운영 스냅샷은 이 파일을 수정해 만드는 대신 Raw DB → Staging → 사람 승인 → 승인 배치 → 스냅샷 내보내기로 생성한다. 공개 배포 도구는 prototype을 거부한다.

12개 학과와 공용 시설의 공식 경로, robots 확인 결과, 원문 보관 제한, 대표 선정 기준은 [source-policies/README.md](source-policies/README.md)에 있다. 이 조사 파일은 자동 수집 허가나 사람의 공개 승인에 해당하지 않는다.

`departments.json`은 공대 공식 학과/학부 목록에서 직접 확인한 12개 학과의 정규 ID 기준이다. 전체 배치를 만들 때 이 ID를 사용한다. 학과가 누락되거나 등록되지 않은 학과를 추가하면 출시 검사에서 차단한다. 공식 목록 변경 시 출처와 확인일을 갱신하며, 대학원 협동과정이나 공용시설을 학과 수에 섞지 않는다. 공용 인프라는 `groupType: shared`인 화면 그룹을 만들고 자원의 `departmentId`로 그 그룹 ID를 참조한다. 이는 학과 소속 주장이나 새로운 탐색 자원 종류가 아니다.
