# 카탈로그 데이터

개발 웹/API의 기본 데이터는 `college-draft.json`이다. 12개 학과의 교수 후보 341명·연구실 237곳, 공용 장비 후보 209개·공간 20곳, 출처 있는 관계 230개, 학과별 논문 근거 12건을 포함한다. 공대 교수검색과 10개 학과 현직 목록·상세를 대조했다. 건축·컴퓨터의 전체 분모, 동명이인과 목록 간 차이, 개별 연구실 주소 등은 추가 검수가 필요하다. 전기정보의 동명 연구실 두 쌍은 공식 상세 주소·지도교수가 달라 별도 확인 대기 후보로 유지한다. **사람 승인 전 검수 초안**이며 공개 배포 데이터가 아니다. 건축학과 교수의 분야 대표성과 지도 연구실은 추가 확인이 필요하고, 확인되지 않은 관계는 만들지 않았다.

개별 사실과 선정 이유, Raw/Staging 반입 기록은 [drafts/README.md](drafts/README.md)에 있다. Node.js 24에서 다음 명령으로 같은 초안을 재생성한다. 동일 ID의 내용이 다르면 중단하며 승인 배치를 합성하지 않는다.

```sh
node --import tsx data/compile-draft.ts
```

운영 데이터는 사람 승인 후 worker로 내보낸 `public-snapshot.json`을 `IEUM_SNAPSHOT_PATH`로 지정한다. 운영 API는 PostgreSQL 승인 배치가 필수이고, Pages 출시 게이트는 현재 prototype을 거부한다.

## 고정 테스트 표본

`prototype.json`은 2026-10-26 공식 공대 학과 목록과 컴퓨터공학부 교수·연구실 상세 페이지에서 직접 확인한 표본이다. 개인 연락처와 원문 전체는 저장하지 않았다. 이름·소속·연구실 관계·연구 분야의 허용 메타데이터만 수록했다. 출처 URL과 확인일은 파일에 포함한다.

알고리즘·생물정보·인지 분야에서 서로 다른 연구실을 골랐다. 전수/대표성 검증이나 사람의 공개 승인에 해당하지 않는다. 모든 자원은 verificationRequired이며 manifest는 prototype이다. 장비·공간·다른 학과·논문 근거 수량은 아직 미달이다.

운영 스냅샷은 이 파일을 수정해 만드는 대신 Raw DB → Staging → 사람 승인 → 승인 배치 → 스냅샷 내보내기로 생성한다. 공개 배포 도구는 prototype을 거부한다.

12개 학과와 공용 시설의 공식 경로, robots 확인 결과, 원문 보관 제한, 대표 선정 기준은 [source-policies/README.md](source-policies/README.md)에 있다. 이 조사 파일은 자동 수집 허가나 사람의 공개 승인에 해당하지 않는다.

`departments.json`은 공대 공식 학과/학부 목록에서 직접 확인한 12개 학과의 정규 ID 기준이다. 전체 배치를 만들 때 이 ID를 사용한다. 학과가 누락되거나 등록되지 않은 학과를 추가하면 출시 검사에서 차단한다. 공식 목록 변경 시 출처와 확인일을 갱신하며, 대학원 협동과정이나 공용시설을 학과 수에 섞지 않는다. 공용 인프라는 `groupType: shared`인 화면 그룹을 만들고 자원의 `departmentId`로 그 그룹 ID를 참조한다. 이는 학과 소속 주장이나 새로운 탐색 자원 종류가 아니다.

## 학과별 공식 상세 수집

`apps/worker/src/department-profiles-cli.ts`는 정책 검수 설정과 전용 `DATABASE_URL`을 받아 명단·연구 분야·홈페이지·명시 주소의 최소 사실만 Raw/Staging에 수집한다. `cohort`는 `industrial-nuclear-aerospace`, `civil-naval-energy`, `mechanical-materials-electrical-chemical`을 지원한다. 재료는 반복 분야 카드의 공식 상세 주소를 중복 제거하고, 화학생물은 끝 페이지까지 조회하며 반복 페이지를 거부한다. 재실행은 카탈로그를 덮어쓰거나 승인하지 않는다. 원문 HTML·사진·개인 연락처는 보관하지 않는다.

IRF 보유기기 55개와 각 `pop_detail.php`의 명시 `기기활용` 항목을 다시 대조해 43개에 용도를 추가했다. `apps/worker/src/equipment-cli.ts`는 검수 정책과 `outputDirectory` 설정을 받아 같은 최소 사실을 새 Raw/Staging 후보로 수집한다. 현재 필수 정보·위치를 갖춘 장비는 37개이며, 후보 209개를 완료 수로 세지 않는다. ISRC 공식 장비배치 화면에는 1·2층 배치가 있지만 건물 연결이 명확하지 않아 개별 설치 위치로 채택하지 않았다. 예약 현황·신청자·실내 도면은 수집하지 않았다.

기계공학부 공식 김민수 교수 카드의 두 줄 연구실 명칭은 냉동시스템 및 컨트롤 연구실과 연료전지시스템 연구실로 각각 분리했다. 수집기는 `labNames` 배열을 보존하고 복수 표기를 단일 `labName`으로 만들지 않는다. 개별 연구실 홈페이지·주소는 미확인으로 유지하며 이전 통합 배치는 재검수 대상으로 전환했다.
