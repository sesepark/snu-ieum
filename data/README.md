# 시제품 표본

`prototype.json`은 2026-10-26 공식 공대 학과 목록과 컴퓨터공학부 교수·연구실 상세 페이지에서 직접 확인한 표본이다. 개인 연락처와 원문 전체는 저장하지 않았다. 이름·소속·연구실 관계·연구 분야의 허용 메타데이터만 수록했다. 출처 URL과 확인일은 파일에 포함한다.

알고리즘·생물정보·인지 분야에서 서로 다른 연구실을 골랐다. 전수/대표성 검증이나 사람의 공개 승인에 해당하지 않는다. 모든 자원은 verificationRequired이며 manifest는 prototype이다. 장비·공간·다른 학과·논문 근거 수량은 아직 미달이다.

운영 스냅샷은 이 파일을 수정해 만드는 대신 Raw DB → Staging → 사람 승인 → 승인 배치 → 스냅샷 내보내기로 생성한다. 공개 배포 도구는 prototype을 거부한다.

`departments.json`은 공대 공식 학과/학부 목록에서 직접 확인한 12개 학과의 정규 ID 기준이다. 전체 배치를 만들 때 이 ID를 사용한다. 학과가 누락되거나 등록되지 않은 학과를 추가하면 출시 검사에서 차단한다. 공식 목록 변경 시 출처와 확인일을 갱신하며, 대학원 협동과정이나 공용시설을 학과 수에 섞지 않는다. 공용 인프라는 `groupType: shared`인 화면 그룹을 만들고 자원의 `departmentId`로 그 그룹 ID를 참조한다. 이는 학과 소속 주장이나 새로운 탐색 자원 종류가 아니다.
