# 공식 데이터원 확인 기록

`discovery.json`은 12개 학과와 공용 시설의 **경로 조사 기록**이다. 실행 가능한 worker `Policy`나 원문 보관 허가서가 아니다. `automaticIngestionEnabled`는 false이며, 수집기에 그대로 전달할 수 없다. selector는 실제 페이지에서 관찰한 범위만 기록했다. null은 추측해서 채우지 않은 항목이다.

2026-10-26 각 공식 학과 페이지에서 학과 홈페이지 연결을 확인했다. 각 호스트의 `/robots.txt`를 HTTPS로 조회했고, 명시적 제외·응답 실패를 기록했다. 건축학과 전체와 S-Space 상세 경로는 자동 접근에서 제외한다. CSE robots 조회 실패 시 TLS 검증을 끄거나 다른 호스트로 우회하지 않는다. 로그인·검색 결과·다운로드·신청 경로는 수집하지 않는다.

대부분의 footer는 서울대 개인정보처리방침과 저작권 표시를 제공하며, 전체 HTML/PDF의 보관·재배포 허가를 확인할 수 없었다. 개인정보처리방침을 콘텐츠 재사용 라이선스로 취급하지 않는다. 이번 검수 초안은 이름·공식 연구 분야·연구실명·장비명·공간명과 출처 URL 등 최소 사실을 직접 작성한다. 직접 작성한 수동 메타데이터 payload 전체를 Raw DB에 불변 보관하고 Staging으로 넘긴다. HTML·PDF·사진·연락처는 보관하지 않는다. 자동 수집 활성화와 원문 파일 보관은 소스별 명시적 검수 후 별도 Policy로 수행한다.

대표 선정은 순위가 아니다. 학과의 공식 연구 분야에서 서로 다른 분야를 우선해 3개 교수–연구실 사례를 고른다. 선택 이유는 학과별 검수 파일에 남긴다. 명예·전직 교수를 현직 교수로 섞지 않는다. 같은 이름은 소속·공식 프로필·연구실 URL을 확인하고, 불분명하면 후보로 남긴다. 교수–연구실 관계는 같은 공식 카드나 상세 페이지에 명시될 때만 만든다. 연구그룹·학과·센터를 임의로 개별 연구실로 바꾸지 않는다.

공용 장비·공간은 `groupType: shared`인 화면 그룹에 넣는다. 연구실의 이용 권한, 장비의 설치실, 사용료·교육·예약 자격은 원문이 명시한 경우에만 기록한다. 논문 근거는 제목·URL·저자 식별을 검수하며 논문 유사도를 협업 관계로 만들지 않는다.

후속 작업은 공용 장비·공간, 학과별 교수·연구실(2–3개 학과씩), 학과별 논문 근거, 제한 데이터원 수동 제공 확인, 통합 배치 사람 승인으로 나눈다. 초안의 에이전트 확인은 사람의 공개 승인과 다르다.
